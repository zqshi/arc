## 版本目标

环节能力配置 (v6.8.0 已建成) 当前作为平级独立卡片排在项目规范上方且无收起机制, 对大多数用默认配置的项目是视觉噪声。本版本把它重组为"高级配置项"——移到「项目规范」卡片下方, 默认收起, 点击展开。纯前端, 后端零改动 (默认行为不变: 7 环节始终存在, 每环节默认 0 能力, 用户可逐环节勾选)。

## 版本验证标准

1. 项目设置页: 环节能力配置出现在「项目规范」卡片下方 (非原 ExecutionMode 下方位置)
2. 默认收起 (7 环节 grid 不可见), 点击头部展开/收起, 状态正确
3. 展开后勾选能力仍即时保存 (PUT phase-capabilities), toast 正常
4. tsc -b 0 / vitest 全绿 / build 0; 后端零改动无需 pytest

## 版本范围

**做什么:**
- T1: PhaseCapabilitiesSection 自带折叠 (复用 LLMConfigSection 模式: showAdvanced state 默认 false + ChevronDown rotate-180 + 条件渲染) + SettingsTab 把它挪到项目规范卡片下方 + 测试适配

**不做什么:**
- 后端任何改动 (phase_capabilities 默认值/接口/存储全不变)
- 新建通用 Collapsible 组件 (复用 LLMConfigSection 既有约定即可, 不引入抽象)
- 其他 settings 区块的重排 (仅动环节能力配置)
- 折叠状态持久化 (localStorage) — 同 LLMConfigSection, 纯组件 state
