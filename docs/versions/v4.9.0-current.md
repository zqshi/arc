# v4.9.0 — 原型交互端到端 + 预览服务器

> **主题**: 将 v4.7.0 的原型交互能力端到端打通，增加本地预览服务器
> **前置**: v4.8.0 完成

---

## 版本目标

1. 原型修改请求经对话 AI 处理后，将修改后 HTML apply 回 iframe（闭环）
2. 项目级原型本地预览服务器（无需手动打开文件）
3. 原型交付物更新时自动持久化到项目站点目录
4. 前端 prototype bundle 入口优化（从项目详情页直接跳转预览）

## 设计要点

### T1: AI 返回修改后 apply

当用户在原型选中元素并输入修改意图：
1. `onRequestModify` 将上下文发送到对话 (quick message)
2. AI 在对话中返回修改后的 HTML 片段
3. 前端检测到 AI 回复中包含 HTML 代码块 → 提取 → postMessage apply_html 到 iframe

**AI 回复中的约定格式**:
```
修改后:
```html
<h2 class="text-2xl text-blue-500">新标题</h2>
```
```

前端正则匹配 `html 代码块 → 提取内容 → apply。

### T2: 本地预览服务器

后端新增路由: `GET /projects/{id}/prototype-preview`
- 读取 `{local_path}/.arc/prototype/index.html`
- 返回 HTML response (Content-Type: text/html)
- 如果不存在 → 先调用 persist_to_project 生成

### T3: 自动持久化

在 `artifact_extractor.py` 产出 prototype 类型 artifact 后，自动触发 `persist_to_project`。

### T4: 前端入口

项目详情页 header 增加「🖥 预览原型」按钮，新 tab 打开 `/api/projects/{id}/prototype-preview`。
