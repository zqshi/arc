## 版本目标

v2.3.0 让 Agent 有了手脚，但底盘不稳：扫描进度纯靠内存 SSE 流（切 tab 即丢）、项目删除是硬删（不可恢复）、循环依赖/文件超限等架构债务累积。本版本目标是加固底盘：关键状态服务端持久化、项目逻辑删除、消除循环依赖、LLM adapter 接口补齐。

## 版本验证标准

1. 扫描期间切换 tab 再切回，进度/结果不丢失（从 DB 恢复）
2. 项目删除后数据仍在（标记 deleted_at），管理员可恢复
3. 无 application 层循环 import
4. LLM adapter 暴露 `chat_with_tools()` 方法，tool_loop 不再穿透私有属性
5. 所有超 500 行文件拆分到 500 行以下
6. 现有测试全部通过

## 版本范围

**做什么:**
- 扫描状态/进度服务端持久化（scan_status 字段 + 进度写 DB）

- 循环依赖消除（artifact↔pipeline, conversation↔execution）

## 各任务实施要点

### T1 — 扫描状态/进度服务端持久化

**目标**: 扫描进度不依赖 SSE 连接存活，切 tab 再回来能恢复。

**方案**:
1. Project 实体增加 `scan_status` 字段: idle → scanning → completed/error
2. scan_task._run_scan() 每收到 stage/chunk 事件时写 DB（或至少写 scan_status）
3. scan_task._run_scan() 完成/失败时更新 scan_status + scan_error
4. 前端 SettingsTab mount 时：
   - 读 project.scan_status
   - 如果 scanning → 自动调 SSE stream 恢复订阅
   - 如果 completed → 显示 codebase_summary
   - 如果 error → 显示 scan_error

**Migration**: 新增 `scan_status VARCHAR(20) DEFAULT 'idle'`, `scan_error TEXT`

### T2 — 项目逻辑删除

**方案**:
1. Project 实体增加 `deleted_at: datetime | None`
2. `delete()` 方法设置 `deleted_at = now()`，不做物理删除
3. ProjectRepository.list_all() 默认 `WHERE deleted_at IS NULL`
4. 保留硬删除方法供管理员使用（`hard_delete()`）
5. 列表 API 新增 `include_deleted` 参数

**Migration**: 新增 `deleted_at TIMESTAMP WITH TIME ZONE`

### T3 — 循环依赖消除

**环 1: artifact ↔ pipeline**
- artifact/service.py 引用 pipeline/prompts — 将共享的 prompt 提取到独立模块
- pipeline/service.py 引用 artifact/service — 通过接口注入或提升到编排层

**环 2: conversation ↔ execution**
- conversation/service.py 引用 execution/agent_loop — 通过接口/回调解耦
- execution/conversation_strategy.py 引用 conversation/service — 通过构造函数注入

### T4 — LLM adapter chat_with_tools()

给 LLMAdapter 增加方法：
```python
async def chat_with_tools(
    self, messages, tools, *, max_tokens=16384
) -> dict:
    """Call LLM with tool definitions. Returns raw API response."""
```

### T5 — tool_loop 去私有属性访问

将 `self._adapter._client` / `self._adapter._model` 的 4 处直接访问改为调用 `self._adapter.chat_with_tools()`。

## 对后续版本的约束

- Repository 接口补齐后，后续新增 repository 必须在 domain 层定义接口
