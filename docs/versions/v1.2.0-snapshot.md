# v1.2.0 Snapshot — AI对话引擎增强与产品可视化

> 发布日期: 2026-05-25
> 起始 commit: 0846be3 | 上一版本: [v1.1.0](v1.1.0-snapshot.md)

## 版本目标

v1.1.0 完成代码质量加固后, 本版本聚焦对话驱动引擎的核心能力: AgentLoop 可靠续写、DDD方法论注入、原型产品预览、交付物状态一致性。目标是让"一次对话产出完整产品设计"的体验真正可用。

## 交付内容

- **AgentLoop 生产级引擎**: finish_reason 续写/交付物验证重试/预算超时保护
- **交付物拆分 8 环节**: 交互设计/视觉规范/原型设计独立为三个新阶段
- **DDD+TDD 方法论注入**: dev_report schema 重构, conversation_strategy 条件注入
- **项目级领域模型视图**: tech_architecture 自动提取 → DomainModelTab 战略战术可视化
- **AgentLoop 目标驱动 + AutoPilot 自驾模式**: 持续推进直到全部交付物完成
- **交付物状态不一致修复**: regex/JSON解析/race condition 三层修复
- **原型产品预览**: Blob URL 隔离渲染, 真实页面跳转, S3 持久化发布
- **DDD 战略设计注入**: tech_architecture schema 新增 domain_design 字段
- **AbortError 修复**: 前端 SSE/fetch 取消不再弹错误 Toast

## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| AgentLoop 续写策略 | finish_reason 检测 + 自动 continue | 对用户透明, 无需手动触发 |
| AutoPilot 轮次上限 | 12 轮 | 平衡自动化深度与 token 成本 |
| 原型预览架构 | Blob URL (本地) + S3 持久化 (远程) | 开发时零依赖, 部署时可共享链接 |
| DDD 方法论注入时机 | conversation_strategy 条件判断 | 仅 tech_stack 涉及后端时注入, 避免过度设计 |
| 领域模型提取 | 按 name 去重累积合并 | 多 todo 产出的设计自动聚合为项目级全景 |
| 原型 CSP 策略 | connect-src 'none' | 发布的 HTML 不可发起网络请求, 防 XSS 外传 |

## 对后续版本的约束

- AgentLoop 的 LoopConfig 已从项目 conversation_config 读取, 后续可扩展为用户级配置
- tech_architecture schema 新增 domain_design 字段, AI 产出的技术方案必须包含战略设计
- 原型预览已迁移到 S3 持久化, URL 格式为 `previews/{todo_id}/{artifact_id}/index.html`
- DomainModelExtractor 按 name 去重合并, 多个 todo 产出的领域模型会累积到项目级
- AutoPilot 最大轮次 12 轮, 后续可根据任务复杂度动态调整
- ArtifactContent discriminated union 已定义, 新增 artifact 类型需同步前后端类型
- SQL 分页已统一, 新 list 接口必须在 repo 层实现 offset/limit
