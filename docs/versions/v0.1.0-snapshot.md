# v0.1.0 Snapshot — Arc MVP 初始版本

> 发布日期: 2026-05-17
> 对应 commit: 14572c8

## 版本目标

验证"结构化待办 + AI辅助分析 + Agent执行 + 经验沉淀"的端到端链路是否跑通。

## 交付内容

- **M1 项目空间**: Project / Version CRUD, 项目配置, 版本状态流转
- **M2 需求管理**: Todo CRUD, 状态机, 项目/版本关联
- **M3 智能管线**: 7阶段 pipeline, 质量门禁, 跳过/回滚
- **M4 AI对话**: 多轮对话, WebSocket 流式响应, 阶段感知 system prompt
- **M5 Agent编排**: OpenHands 适配器, 多Agent注册表(骨架), 上下文组装
- **M6 经验引擎**: 经验提取, pgvector 语义检索, 三级 scope
- **M7 统一上下文层**: ProjectContextProvider
- **M8 产出物系统**: 7种产出物类型, 版本管理, 10个前端渲染器
- **前端**: 响应式 UI, 种子数据系统, 经验库展示

## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 前端框架 | React + TypeScript + Vite | AI编程工具支持最好 |
| 后端框架 | Python + FastAPI | OpenHands是Python生态, 大模型SDK支持最好 |
| 数据库 | PostgreSQL + pgvector | 全文检索 + 向量语义检索, 商业化扩展性强 |
| Agent集成 | OpenHands (首选) | 开源, API成熟, 支持自托管 |
| 架构风格 | DDD分层 (domain/application/infrastructure/interface) | 业务逻辑和基础设施解耦 |
| 状态管理 | 服务端为主, 前端轻量 | 避免前端状态同步复杂度 |

## 遗留问题

- Agent只有OpenHands可用, Claude Code/Codex/Cursor均为骨架
- 无用户认证, 单用户模式
- 无需求依赖关系
- 经验scope虽有project级别但无project_id, 多项目会混乱
- 无安全加固(CORS/JWT/限流)

## 数据模型要点

- Todo: title, description, status, current_phase, tags, project_id, version_id, priority
- Experience: title, problem, solution, scope(todo/project/global), decisions[], pitfalls[], embedding
- Pipeline: 7 phases (requirement → ui_design → tech_arch → dev → test → deploy → experience)
- Artifact: 7 types, content(JSON), version, confirmed flag
