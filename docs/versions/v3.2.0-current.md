# v3.2.0 Current — 领域模型升级执行机制

> 状态: 进行中
> 前置版本: [v3.1.0](v3.1.0-snapshot.md)
> 升级路径阶段: Phase 3 / 3

## 版本目标

把影响分析的决策转化为系统可执行的动作：暂停受影响需求、执行模型升级、恢复需求继续推进。

## 版本验证标准

1. Todo 支持 SUSPENDED 状态，可因模型升级暂停/恢复
2. ModelUpgradeOrchestrator 能按策略（block/defer）编排升级流程
3. 恢复后的 Todo 能正常继续 pipeline
4. 后端测试全量通过

## 版本范围

**做什么:**
- Todo SUSPENDED 状态 + 状态机扩展
- ModelUpgradeOrchestrator 编排器
- 升级流程 API 端点
- 单元测试

**不做什么:**
- 前端升级交互 UI → 后续版本
- 交付物自动重新生成 → 后续版本（本版本仅标记需重新审视）
- 自动触发升级（本版本需用户主动发起）
