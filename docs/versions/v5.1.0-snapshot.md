# v5.1.0 — 版本发布自动 Changelog + 需求优先级可视化

> **状态**: released
> **日期**: 2026-06-04

## 目标

- 版本发布时 AI 自动总结需求列表生成 changelog
- 需求列表展示优先级标签（P0/P1/P2 可视化）
- 需求创建时支持选择优先级

## 交付

| ID | 任务 | 交付物 |
|----|------|--------|
| T0 | prompt_builder 上下文注入改造 | `provider.py` + `conversation_strategy.py` |
| T1 | 版本发布自动 changelog | `service.py` AI changelog + fallback |
| T2 | 优先级标签可视化 | `TodoListItems.tsx` + `TaskCard.tsx` P0/P1/P2 |
| T3 | 创建时选优先级 | `CreateTodoModal.tsx` 优先级选择器 |

## 关键决策

- **上下文注入架构**: 通过 `ProjectContextProvider._get_analysis_summary()` 在 provider 层注入，不侵入 prompt_builder 本身
- **Greeting 策略**: 不调 LLM（避免 init 延迟），基于已有数据动态模板化；真正的上下文感知通过 system prompt 注入
- **Changelog 降级**: AI 生成失败时自动降级为简单 bullet list
