# v1.1.0 Snapshot — 代码质量加固与工程规范补全

> 发布日期: 2026-05-25
> 起始 commit: 0b6bea1 | 上一版本: [v1.0.0](v1.0.0-snapshot.md)

## 版本目标

v1.0.0 完成多用户与团队全栈实现后, 审计发现测试覆盖不足、部分接口缺少分页、前端核心组件过度膨胀。本版本聚焦代码质量加固, 为后续商业化打好工程基础。

## 交付内容

- **路由装饰器修复**: todo.py get_dependencies 缺失 @router.get 装饰器
- **列表接口分页**: 所有列表 API 统一支持 page/page_size 参数
- **Docker 密码外部化**: docker-compose.yml 敏感配置通过 .env 注入
- **TodoDetail 拆分**: 1200+ 行单文件拆为 pages/todo/ 下独立子组件 (每文件 < 400 行)
- **前端静默错误修复**: 消灭 .catch(() => {}) 模式, 改为 Toast 通知
- **硬编码 localhost 修复**: 统一走环境变量
- **auth service 单元测试**: 覆盖注册/登录/token刷新/密码校验
- **route 冒烟测试**: 全路由 404/401 基本响应验证

## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 分页参数 | page/page_size (非 skip/limit) | 前端友好, 与主流 API 规范一致 |
| TodoDetail 拆分策略 | 按功能拆 (ConversationMode/PipelineMode/Header) | 职责单一, 各组件可独立演化 |
| 错误处理模式 | Toast 通知用户 + console.error 保留调试 | 平衡用户体验与可调试性 |
| WebSocket 地址 | 从 location.host 动态推导 | 避免硬编码, 支持任意部署环境 |
