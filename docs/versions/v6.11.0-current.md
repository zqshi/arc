## 版本目标

质量检测发现项目功能完整但距投产有硬缺口: k8s 生产部署仅 3 服务(缺 DB/对象存储/沙箱/agent 运行时)、17 个后端端点无前端入口、核心 service 缺测试、错误体系混用、6 个文件超限。本版本目标: 消除投产硬缺口(k8s 完整 + 功能完整)并补齐测试保护, 为投产就绪奠定基础。代码质量重构(错误规范化 + 文件拆分)作为后半程推进。

## 版本验证标准

1. k8s manifests 覆盖 docker-compose 全部 6 服务, configmap 字段与 config.py 双向对齐, kustomize build 通过
2. organization/template 后端能力在 webui 有操作入口(页面 + 路由 + 导航)
3. deployment/billing service 有单元测试覆盖
4. 质量检测协议 6.1-6.7 必修项通过
