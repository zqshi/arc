# v2.9.0 Snapshot — 架构治理 + 测试补全

> 完成日期: 2026-06-01
> 起始 commit: 9630a36
> 上一版本: [v2.8.0](v2.8.0-snapshot.md)

## 版本目标

消除 application 层循环依赖，补齐 domain value_objects 测试覆盖，拆分超限文件。

## 交付物

1. **循环依赖消除**: 8 条循环依赖全部解除（2 条顶层 + 6 条延迟 import）
2. **value_objects 测试**: 8 个模块补齐，新增 206 tests，覆盖率从 11% 提升到 90%+
3. **超限文件拆分**: llm_adapter.py 581→3 文件, ws/chat.py 564→4 文件

## 关键决策

| 决策 | 选项 | 理由 |
|------|------|------|
| 循环依赖解法 | prompts 模块上移为 context/prompts.py | 共享类型独立化，打破双向耦合 |
| 延迟 import 策略 | DI 注入 + 内联 fallback + 顶层化 | 从架构上消除而非仅规避运行时错误 |
| llm_adapter 拆分 | 基类留原文件，子类独立文件 | 继承关系清晰，每文件 <250 行 |
