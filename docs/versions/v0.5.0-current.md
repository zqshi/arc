# v0.5.0 Current — 经验引擎深化

> 状态: 进行中
> 起始: 2026-05-21
> 上一版本: [v0.4.0](v0.4.0-snapshot.md)

## 版本目标

经验从"能用"升级为"好用" — 经验有半衰期自动衰减, 可从项目经验一键提炼为个人经验, 用户能直接编辑经验内容。

## 版本验证标准

1. 经验条目的 confidence 随时间自动降低, 过期经验有视觉标记
2. 项目经验可一键提炼为个人经验, 提炼后保持关联
3. 经验详情页支持富文本编辑, 保存后立即生效

## 版本范围

**做什么:**
- 经验提炼: 项目经验 → 个人经验 (P1)
- 经验衰减机制: confidence 随时间降低 (P1)
- 经验编辑能力增强 (P2)
- 经验复用效果追踪: reuse_count 分析 (P2)

**不做什么:**
- 多用户/权限 → v1.0
- Agent 多步骤编排/自动 retry → v0.6.0+
- Cursor 适配器 → 等官方 API 稳定
- 经验模板市场 → v2.0

## 各任务实施要点

### T1 — 经验衰减

**衰减模型**: confidence = original_confidence × decay_factor^(days_since_creation / half_life_days)
- `half_life_days` 默认 180 天, 可配置
- 定时任务每日凌晨批量更新 confidence
- 低于阈值(0.3)的经验标记为 `stale`

**改动点**:
- `domain/experience/entity.py`: 增加 `half_life_days`, `is_stale` 属性
- `application/experience/service.py`: 增加 `decay_batch()` 方法
- 定时任务注册到 FastAPI lifespan 或 APScheduler

### T3 — 经验提炼

**提炼流程**:
1. 用户在项目经验详情点"提炼为个人经验"
2. 后端创建新的个人经验(scope=personal), 保留原始关联(source_experience_id)
3. AI 辅助提炼: 去掉项目特定细节, 提取通用模式

**数据变更**: Experience 表增加 `source_experience_id` 字段(自引用 FK)

## 对后续版本的约束

- 衰减机制的 half_life_days 需要支持按项目自定义
- 提炼关联(source_experience_id)不可断开, 用于追踪经验演化链路
- 编辑经验时不改变 confidence, 但重置 updated_at
