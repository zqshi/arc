## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| Skill 集成方式 | Prompt 注入 (非外部脚本) | 无外部依赖、与现有对话流无缝融合 |
| 方法论注入时机 | PromptBuilder 根据已完成 deliverable 动态选择 | 不需要用户手动切换 |
| Playwright 执行方式 | 独立子进程 (asyncio subprocess) | 沙盒隔离、超时保护、不共享主进程状态 |
| Pipeline ToolAwareLoop | 有 project_path 时自动升级 | 优雅降级——无路径时回退文本模式 |
| Gate 增强方式 | 三层 (结构 + 方法论 + 交叉) 可选开启 | 向后兼容，不破坏现有 gate 行为 |

## 对后续版本的约束

- 新增的方法论模块 (`*_methodology.py`) 必须通过 `PromptBuilder` 注入，不得在其他层直接引用
- `playwright_sandbox.py` 依赖系统安装 playwright，未安装时所有函数返回 `success=False`
- Gate 的 `prior_artifacts` 参数是可选的——调用方不传时退化为纯结构检查
