# v6.10.0 Current — B 流程引擎内容编排（methodology/prompt/gate 可配置）

> 起始 commit: 674a4a9 (2026-06-27)
> 上一版本: [v6.11.0](v6.11.0-snapshot.md)

## 版本目标

将环节逻辑内容（methodology 方法论引导 / prompt 阶段提示词 / gate 门禁检查项）显性化为可配置模型，使流程引擎中枢从"硬编码 prompt + 规则门禁"演进为"内容可编排"。当前 methodology/prompt/gate 散落在代码常量与 provider 内部，新增/调整环节逻辑需改代码。本版本目标：让这些内容可声明管理（DB 持久化或配置驱动），不推翻现有 Provider 管道与7阶段骨架。

## 版本验证标准

1. 环节方法论（methodology）可按项目类型/环节声明，无需改 context/providers/methodology.py
2. 阶段提示词（PHASE_EXTRACTION_PROMPTS 等）可配置，存量行为不破
3. 门禁检查项（conversation_gate）可编排，门禁走 LLM 延伸（延续 v6.8 决策，非规则引擎）
