## T1 方案设计：methodology/prompt/gate 可配置（配置文件方案）

> 状态: 设计完成 (2026-06-27), 待 T2-T5 实施
> 决策: 配置文件方案 (git 版本控制, 无 DB) — 用户拍板

### 选定方案
配置文件方案。内容脱离业务逻辑, git 版本控制, 随版本发布。无 DB/migration/缓存/管理界面开销。

### 载体选型: Python 常量模块 (非 YAML)
评估后选 Python 常量模块而非 YAML:
- arc 无 pyyaml 依赖, 引入需新增依赖 (CLAUDE.md "不引入新依赖前评估")
- prompt 是大段文本, Python 多行字符串 (`"""..."""`) 可读性不输 YAML
- Python 常量仍是 git 版本控制, 满足"配置文件方案"核心诉求
- 无运行时解析开销 (YAML 需 pyyaml parse)
> 若后续需非开发人员编辑, 再引入 YAML + 管理界面 (留 backlog)

### 设计原则
1. **内容可编排, 管道不变** (延续版本范围): 纯内容 (prompt 文本/字段规则/阈值/profile) 可配置; 编排逻辑 (路由/评估流程/子步骤控制) 保持代码
2. **复用 v6.9 模式**: dict + `.get(key, default)` fallback, 配置缺失回退默认 (DELIVERABLES_BY_TYPE 范式)
3. **一次性迁移, 无运行期双读**: 内容从代码内联迁到 content 模块, 消费方改读 content; 不引入 DB 双读复杂度 (区别于 DB 方案的运行期双读)
4. **strict 模式逻辑模块保留**: methodology strict 的 clarification_strategy/ui_design_methodology 等含路由/子步骤逻辑, 非纯内容, 保留代码

### 配置模块结构 (`application/context/content/`)
- `methodology.py` — methodology prompt dict (constraint × phase × depth) + prototype_guide (by project_type)
- `phase_prompts.py` — PHASE_SYSTEM_PROMPTS / PHASE_EXTRACTION_PROMPTS / _PHASE_INFERENCE_PROMPT
- `gate.py` — DELIVERABLE_REQUIRED_FIELDS / GateProfile 阈值 / GATE_EVALUATION_PROMPT
- `registry.py` — 统一读取入口 + .get fallback (T5)

### 可配置边界
| 内容 | 可配置 (纯内容) | 保留代码 (编排逻辑) |
|------|----------------|---------------------|
| methodology | free baselines, moderate 精简 prompt, prototype_guide | strict 子模块 (clarification_strategy 路由, *_methodology 子步骤) |
| prompt | PHASE_SYSTEM/EXTRACTION_PROMPTS, _PHASE_INFERENCE_PROMPT | prompt_builder 组装逻辑 |
| gate | DELIVERABLE_REQUIRED_FIELDS, GateProfile 阈值, GATE_EVALUATION_PROMPT | 4 层评估流程 (结构→方法论→一致性→LLM) |

### 三类内容迁移映射
| 现位置 | 迁到 | 消费方改读 |
|--------|------|-----------|
| constraint_policy.py baselines/moderate | content/methodology.py | get_methodology_prompt_for_constraint |
| context/prompts.py get_prototype_guide | content/methodology.py | MethodologyProvider |
| pipeline/prompts.py PHASE_*PROMPTS | content/phase_prompts.py | prompt_registry, artifact/service |
| context/prompt_builder.py _PHASE_INFERENCE_PROMPT | content/phase_prompts.py | prompt_builder |
| domain/artifact DELIVERABLE_REQUIRED_FIELDS | content/gate.py | conversation_gate |
| gate_threshold.GateProfile | content/gate.py | conversation_gate, gate |
| pipeline/prompts.py GATE_EVALUATION_PROMPT | content/gate.py | conversation_gate, gate |
