# v0.3.0 Snapshot — 生产化加固与智能化升级

> 发布日期: 2026-05-21
> 起始 commit: 01b4074 | 末尾 commit: 894b979
> 上一版本: [v0.2.0](v0.2.0-snapshot.md)

## 版本目标

将 Arc 从"能跑"升级为"能用"——安全性达到可部署标准, 核心交互体验打磨, 为多项目场景打基础。

## 交付内容

- **安全加固**: JWT secret校验, 种子账号隔离, SMS防暴力枚举, CORS生产加固, API限流中间件
- **生产化**: 列表分页, DB连接池配置, Docker多阶段构建, Request tracing
- **智能化**: 代码库扫描与AI总结, 规划引擎(PlanningService+DocumentService), 执行模式升级, 经验系统升级
- **体验**: PWA支持(Workbox+SW), WS Token自动续期, 蓝点未读修复, Mermaid动态加载
- **基础设施**: 前端测试框架(Vitest+Testing Library), CI文档新鲜度检查, 种子数据迁移至seeds包, README重写

## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 代码扫描 | 后端异步任务 + SSE流式推送 | 扫描耗时长, 不能阻塞请求 |
| 规划引擎 | PlanningService + DocumentService | 分离规划逻辑和文档持久化 |
| PWA | Workbox + Service Worker | Vite生态集成成熟 |
| 前端测试 | Vitest + Testing Library | 与Vite生态一致, 零配置 |
| 限流策略 | IP滑动窗口, 全局120/min, LLM接口20/min | 防DDoS, 保护AI调用成本 |

## 对后续版本的约束

- 所有新的列表API必须支持分页(skip/limit参数)
- 新中间件需注册到rate_limit白名单或配置独立限流规则
- 前端新页面必须支持PWA离线降级(至少显示缓存数据)
- 数据库新表必须在migration中添加必要索引
- commit message 格式: `type: 中文描述`
