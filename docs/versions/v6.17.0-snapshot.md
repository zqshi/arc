# v6.17.0 Snapshot — Skill 注入执行链（架构统一 + 工具集补全）

> 状态: 已归档 (2026-06-29)
> 起始 commit: e34a6ed
> 上一版本: [v6.16.0](v6.16.0-snapshot.md)

## 版本目标

让 skill 对称注入对话侧与执行侧 (统一 provider 取数层), 把 skill 工具集做成完整可执行体系 (inline function + MCP 引用, 按 agent 能力分发)。对齐产品预期"配置了 skill 的环节按 skill 规范注入执行, 不仅影响对话"。

## 交付内容

- **T1 数据模型**: ToolSpec 值对象 (source=inline|mcp); SkillLoader.load_full 返回 SkillContent (prompt + tool_specs), 用 yaml 解析 SKILL.md frontmatter 的 tools 字段; TaskContext 加 skill_specs/tool_specs/mcp_servers 字段, to_markdown 输出"本环节技能规范"+"本环节启用工具"段
- **T2 架构统一 (核心闭环)**: CapabilityProvider.load_phase_skills (对话侧 provide / 执行侧 build 共享 _collect_active_caps, 单一真相源); TaskContextBuilder.build 接 phase_type; session_manager 透传 — skill 真正进 coding agent 执行链 (3 adapter 经 to_markdown 自动生效)
- **T3 Codex 工具注入**: CodexAdapter._build_tools 把 inline function 注册为 /responses 的 tools (Responses API 顶层 name/description/parameters 格式), code_interpreter 兼容
- **T4 MCP 消费侧**: McpClient (stdio 子进程 + http POST 传输, JSON-RPC 2.0); McpLoader 转 ToolSpec(source=mcp); CapabilityType.MCP 激活 + is_mcp property; load_phase_skills 集成 mcp (tool_specs + 连接配置)
- **T5 agent MCP 注入适配**: ClaudeCodeAdapter --mcp-config (真注入, agent 直连 MCP server 调工具); OpenHands (per-session config 不支持) / Codex (fire-and-forget 无 function call 路由) 按 agent 能力降级为 to_markdown 指引文本
- **T6 schema + 前端**: capability config 支持 source/directory/content (tools 在 SKILL.md frontmatter, inline textarea 已支持编辑); MCP hint 更新 + 配置提示明确化; PhaseCapabilitiesSection 已支持选 skill/mcp; pyyaml 显式声明 (避免 transitive)
- **T7 测试**: 单测 (ToolSpec 7 / SkillLoader 8 / load_phase_skills 6 / McpClient 4 / McpLoader 9 / Codex 5 / ClaudeCode 4 / TaskContext 6) + 集成测 (配 skill → build → agent context 含 skill 端到端 3)

## 关键技术决策

| 决策 | 理由 |
|------|------|
| 统一 provider 取数层, 不合并产物形态 | ContextAssembler→system prompt (对话) / TaskContext→markdown (执行) 各自契约不变, 避免破坏 agent 契约与对话链路 |
| skill 工具集 ToolSpec (source=inline\|mcp) | 两类来源统一表达, 按 agent 能力分发注入 |
| 工具集注入按 agent 能力适配 | Codex 注册 function (API 原生) / ClaudeCode --mcp-config (CLI 原生) / OpenHands 自管工具集 (降级指引); 不抹平不对称, 作为已知约束 |
| load() 向后兼容, 新增 load_full() | 现有 8 个 SkillLoader 测试 + CapabilityProvider.provide 不破坏, 渐进升级 |
| pyyaml 显式声明 | alembic 带入但 skill_loader 直接 import, 显式声明避免 transitive (对齐 cryptography 惯例) |

## 遗留问题

- MCP 真注入仅 ClaudeCode --mcp-config; OpenHands (per-session config 不支持) / Codex (无 function call 路由) 靠 to_markdown 指引文本降级, 非真工具注册 → v6.18 候选
- ClaudeCodeAdapter._write_mcp_config 临时文件未显式生命周期清理 (OS tmpdir 兜底) → v6.18 候选
- McpClient HttpMcpTransport 为 streamable HTTP 简化版 (单次请求/响应, 非完整 SSE 流) → v6.18 候选
- 端到端真实 agent 验证待环境就绪 (OpenHands localhost:3000 未启动 / Codex api_key 未配); 单测+集成测覆盖注入逻辑
