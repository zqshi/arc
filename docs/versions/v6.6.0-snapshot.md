- **route 逻辑泄漏抽 service**: 新建 SettingsService/TemplateService, 扩展 ExperienceService(create/update), 3 处 route 降至参数校验+调用(+32 单测)

- **service 方法 TDD 拆分**: deploy/extract_from_todo/confirm_phase/execute 4 个超 80 行方法全拆, 测试网保护下修 2 真实 bug(GateResult UnboundLocalError + ToolLoopEvent NameError)
- **useConversationSocket onmessage 分发器**: 180 行 switch → 分发器 + 4 子函数(全 <80 行, +14 单测)
- **T1 ExperienceInjectionLog 孤儿表清理**: analytics.py 删除后 model+migration 成孤儿, 新增 z16 migration drop(down_revision=z15, downgrade 复用建表), 删 model。revision id 受 alembic_version.version_num varchar(32) 约束须 ≤32 字符(初版 34 字符超限致 upgrade 失败, 已修正为 z16_drop_injection_logs)
- **T2 artifact-renderers lazy 统一**: 11 个 renderer 顶层 import → lazy()+Suspense 自包含(调用方零改动), 12 renderer 切独立 chunk, 首屏不再加载
