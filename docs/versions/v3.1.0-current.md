# v3.1.0 Current — 领域模型影响分析

> 状态: 进行中
> 前置版本: [v3.0.0](v3.0.0-snapshot.md)
> 升级路径阶段: Phase 2 / 3

## 版本目标

当评审反馈建议修改领域模型时，系统能自动分析"动这个会影响哪些进行中的需求"，给出风险等级和处理建议。

## 版本验证标准

1. `ImpactAnalyzer.analyze()` 能正确识别受影响的 ACTIVE todos
2. 阶段风险矩阵覆盖 PhaseType × ModelChangeScope 全组合
3. 影响报告 API 可用
4. 后端测试全量通过

## 版本范围

**做什么:**
- ImpactAnalyzer — 分析模型变更对进行中需求的影响
- 阶段风险矩阵 — PhaseType × ModelChangeScope → RiskLevel
- ImpactReport 值对象
- 影响分析 API 端点
- 单元测试

**不做什么:**
- 前端影响报告 UI → 前端版本单独排
- Todo SUSPENDED 状态 → v3.2.0
- 自动阻断/恢复机制 → v3.2.0
