# v6.8.0 Current — 能力注册表: Agent/Skill 声明管理 + 环节级配置

> 状态: 进行中 (v6.7.1 发版后激活, v6.7 候选方向暂挂)
> 起始 commit: ee90d4d (2026-06-26)
> 上一版本: [v6.7.0](v6.7.0-current.md) (v6.7.1 milestone 已发, 版本未归档)

## 版本目标

补全 Arc 的"能力运行时入口": agent/skill 可声明管理 (DB 持久化), 项目按环节 (固定7阶段) 配置可用能力, 执行时按环节注入, 门禁按环节能力生成检查项。收敛自需求评审: 环节内能力可配 (非环节自定义, 保研发链路定位) + skill=SKILL.md 能力封装 + MCP 不做 (预留扩展位) + 门禁走 LLM 延伸 (非规则引擎)。

## 版本验证标准

1. 可声明管理 agent/skill 能力 (CRUD + 启用/禁用)
2. 项目可按环节配置可用能力, 执行时该环节对话注入对应能力 (skill 注入 prompt / agent 影响可用集合)
3. 门禁按环节启用能力生成检查项, 能力违规可阻断推进

## 版本范围

**做什么:**
- 波次1: 能力注册表骨架 (domain/capability + DB + CapabilityService + route)
- 波次2: agent 声明迁移 (env→DB, 双读兼容) + skill SKILL.md 加载器
- 波次3: 环节级配置 (pipeline_config.phase_capabilities) + 执行注入 + 门禁 LLM 延伸 + 前端管理页

**不做什么:**
- MCP 接入 → 预留 CapabilityType.MCP, loader 不实现, 视生态后续定
- 自定义环节 → 固定7阶段, 保研发链路定位 (v6.8 之后讨论)
- 门禁规则引擎/DSL → LLM 延伸替代
- 能力运行时热加载 → 按会话读取, 热加载记技术债务
