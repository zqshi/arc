# v0.5.0 Snapshot — 经验引擎深化

> 发布日期: 2026-05-21
> 起始 commit: f8159ca | 末尾 commit: ed145d5
> 上一版本: [v0.4.0](v0.4.0-snapshot.md)

## 版本目标

经验从"能用"升级为"好用" — 经验有半衰期自动衰减, 可从项目经验一键提炼为个人经验, 用户能直接编辑经验内容。

## 交付内容

- **经验衰减**: 半衰期模型(默认180天), 定时批量衰减任务, is_stale 标记 + 前端过期视觉标记
- **经验提炼**: 项目经验 AI 辅助提炼为个人经验, source_experience_id 关联追踪, `/distill` 端点
- **编辑增强**: UpdateExperienceRequest 扩展 category/source/tags/half_life_days, 前端类型下拉/半衰期输入
- **复用追踪**: `/analytics/reuse` 端点(按类别聚合、top 复用、过期统计), 经验库页面过期统计
- **仪表盘清理**: 移除低价值 DashboardTab 及关联后端 API

## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 衰减模型 | 指数衰减 confidence × 0.5^(days/half_life) | 数学意义明确, half_life 可配置, 符合知识老化直觉 |
| 衰减执行方式 | asyncio 后台任务 (lifespan) | 无需额外基础设施, 适合单实例部署阶段 |
| 提炼 vs 升级 | 新建 /distill 端点, 保留原 /promote | distill 创建新实体+AI提炼, promote 仅改 scope; 两者语义不同 |
| source_experience_id | 自引用 FK, ON DELETE SET NULL | 保持经验演化链路, 源经验删除不影响衍生经验 |
| 仪表盘移除 | 直接删除组件+API | 数据在版本进度条和经验库页面已有更好展示 |

## 遗留问题

- 无

## 对后续版本的约束

- 衰减机制的 half_life_days 需支持按项目自定义(当前为全局默认 180 天)
- source_experience_id 关联不可断开, 用于追踪经验演化链路
- 编辑经验时不改变 confidence, 但重置 updated_at
- 多实例部署时需将衰减任务改为分布式调度(当前 asyncio 仅单实例安全)
