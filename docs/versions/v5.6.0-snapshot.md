## 关键决策

### 1. dev 默认复用 Arc PG 同库隔离
- `supabase_db_url` 留空则复用 `database_url`，靠 `arc_{project_id}` 前缀 schema 隔离
- 不强制开发期 `supabase start`；生产配真实 Supabase DSN

### 2. T9 不做 DomainModelSnapshot 结构扩展
- T8 已证明从 `aggregates/fields` 可完整推导 BaasSchema
- 加 `tables` 会造成双事实来源，拒绝

### 3. RLS 校验不阻断
- 借鉴 XSpace 5 项检查（RLS 启用/user_id DEFAULT/SELECT 策略/INSERT WITH CHECK/anon 全放行）
- 返回 warnings 仅记录，人工审批 gate

### 4. MCP 原生 endpoint 而非 Higress to-MCP
- Higress to-MCP 配置语法无法在线核实，凭记忆写配置不负责任
- Arc 提供 JSON-RPC 2.0 原生 MCP 接口（/api/mcp）
- Higress 可前置做透传/网关，不依赖其 to-MCP 转换
- update_artifact 走 filter_editable_fields 白名单（与 UI 一致）

### 5. 增量 DDL 防丢数据
- 全 IF NOT EXISTS，不允许 DROP COLUMN
- model_version 单调递增（实体状态机校验，回退抛 DomainError）

## 领域模型设计

### domain/baas/
- `value_objects.py`: ColumnDef/TableDef/RlsPolicy/StateTransition/ActionDef/BaasSchema + BaasStatus 状态机
  - BaasSchema 强制 `arc_` 前缀（Supabase schema 隔离约定）
- `entity.py`: BaasInstance（apply_model 仅 active 态，version 单调递增防回退）
- `repository.py`: BaasRepository Protocol
- `errors.py`: ProvisionError/SchemaApplyError/RlsValidationError（DomainError 子类）

### application/baas/
- `service.py`: BaasService（provision 幂等/apply_model 编排/introspect）+ apply 后自动 RLS 校验
- `domain_model_applier.py`: Snapshot→BaasSchema 转换（聚合→表，字段→列，id→UUID 主键）
- `rls_validator.py`: 5 项安全检查，返回 RlsWarning 列表

### infrastructure/baas/
- `supabase_client.py`: asyncpg 直连 + schema 名校验（防注入）+ SET search_path 隔离
- `sql_generator.py`: 纯函数 DDL 生成（标识符白名单）
- `rls_generator.py`: DROP+CREATE POLICY 幂等
- `schema_provisioner.py`: provision + introspect 元模型表

### interface/routes/mcp.py
- POST /api/mcp: JSON-RPC 2.0（initialize/tools/list/tools/call）
- tools: arc_list_artifacts/arc_get_artifact/arc_update_artifact

## 约束（延续到 v5.7.0）

- **Supabase 环境强依赖**：生产需真实 Supabase Postgres；dev 默认复用 Arc PG 同库隔离
- **DomainModelSnapshot 兼容**：旧格式（无 aggregates）graceful 跳过 BaaS apply
- **增量 DDL 风险**：N→N+1 不允许 DROP COLUMN，破坏性变更需人工确认
- **RLS 泄漏风险**：rls_validator 仅 WARNING 不阻断，人工审批 gate
- **裸 PG 测试约束**：`auth.uid()` 和 `authenticated`/`anon` role 是 Supabase 预置，裸 PG 集成测试需预创建 role + 用兼容表达式
