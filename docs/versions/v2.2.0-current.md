# v2.2.0 Current — 交互体验优化 + 质量审计债务清偿

> 状态: 进行中
> 起始 commit: bce35c2 (2026-05-27)
> 上一版本: [v2.1.0](v2.1.0-snapshot.md)

## 版本目标

消化 v2.1.0 后质量审计发现的技术债务（测试覆盖不足、大文件超限、部署配置占位符），同时推进交互体验改善（交付物抽屉挤压式布局）。本版本以"还债+打磨"为主，不引入新的大功能。

## 版本验证标准

1. 交付物抽屉挤压式布局可用，对话区域可持续沟通，拖拽调宽流畅
2. 后端 domain 层 + application 层核心模块均有对应测试文件
3. 所有源文件 < 800 行（seeds 例外需注释说明）
4. `npm run build` 和 `pytest` 全量通过
5. k8s 配置无硬编码占位符

## 版本范围

**做什么:**
- 交付物抽屉挤压式布局 (已完成)
- 后端测试覆盖补齐 (domain + application)
- 大文件拆分 (seeds/data.py, seeds/gateway.py, api/client.ts)
- k8s 镜像名参数化

**不做什么:**
- 新功能开发 → v2.3.0+
- 前端测试补齐 → v2.3.0（本版本聚焦后端）
- CI/CD 流程升级 → backlog
