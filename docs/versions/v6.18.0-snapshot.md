## 关键技术决策

| 决策 | 理由 |
|------|------|
| import 环用契约/工厂分离, llm_adapter 保留 re-export | 解 5 个循环依赖 (LLM/EventBus/Sandbox/Context); re-export 让旧调用方零改, 避免大面积改 import |
| v6.18 定位投产治理升级, 不新增产品功能 | 上线前阻断项优先, 产品方向演进与治理解耦 |
| ARC_SANDBOX_BUILDER_IMAGES 留空用注释而非裸空值 | dict 字段空字符串 pydantic-settings 解析失败; 注释 (不设) = 用 DEFAULT_BUILD_IMAGES 注册表, 符合 config "留空则用注册表" 语义 |
| ARC_WORKERS 改注释而非删 | 它是 uvicorn 启动参数 (compose/k8s 读), 非 arc Settings; 留注释说明归属, 避免用户误填入 .env 触发 forbid |
