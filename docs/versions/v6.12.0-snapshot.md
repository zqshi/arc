## 关键决策

### WEB target 绑 BINARY_APP (化解 v6.0 矛盾)
v6.0 snapshot 自承 WEB"接近 STATIC_SITE 重复"。推演 ProjectType 仅 STATIC_SITE (宿主直跑 npm build) + BINARY_APP 两类, WEB 不应绑 STATIC_SITE (真重复), 应绑 BINARY_APP, 语义 = "BINARY_APP web 资源构建 (产 dist, 不打包原生客户端)"。BINARY_APP 三构建形态: tauri_linux (桌面包) / web (dist) / capacitor_apk (apk)。

### android 镜像强制 amd64 (ARG BUILD_TARGET_PLATFORM)
Android build-tools 的 aapt2 等是 x86_64 ELF, 无 arm64 linux 版。arm64 镜像跑 x86 aapt2 触发 Rosetta 但缺 x86 ld-linux (rosetta error)。强制 amd64: x86_64 CI/服务器原生跑; Apple Silicon 经 Rosetta 翻译整个 amd64 镜像 (含 x86 ld-linux + 原生 x86 aapt2)。用 ARG (非 --platform 常量) 避免 buildx warning。

### JDK 21 (非 17)
capacitor 7 的 @capacitor/android 要求 source/target 21, JDK 17 报 `invalid source release: 21`。镜像升级 eclipse-temurin:21-jdk。

### capacitor kotlin 版本统一归项目配置
smoke 发现 capacitor 7 + kotlin-stdlib 1.8.22 vs jdk8 1.6.21 重复类 (checkDuplicateClasses 失败)。这是 capacitor 模板依赖冲突, 非镜像缺陷。arc build_command 保持标准 (npx cap build android), 用户项目需在 build.gradle 配 kotlin 版本统一。记入 BUILD_GUIDE 提示。

### build_target 注入: capacitor_apk 大内存
capacitor_apk 构建重 (gradle+jvm+aapt2+dex), SandboxPolicy 默认 512MB 不足。T3 注入时 capacitor_apk 额外 memory_limit_mb=4096; web/tauri_linux 走默认 (tauri 已 v6.0 验证, vite 轻)。

## 遗留 (技术债)

- **capacitor kotlin 项目配置**: capacitor 7 项目需配 kotlin 版本统一 (stdlib 1.8.22 vs jdk8 1.6.21 重复类)。arc build_command 标准, 用户项目配置。待 BUILD_GUIDE 提示 + 真实项目验证。
- **android release build**: `cap build android` (release) 的 checkReleaseDuplicateClasses 同样受 kotlin 重复影响。smoke 用 assembleDebug (debug apk) 验证工具链; release 签名分发待用户项目 kotlin 配置正确后验证。
- **runtime --shm-size 未验证**: 本地 smoke 手动加 --shm-size=2g 通过; DockerSandboxRuntime 的 docker run 默认 64m shm 未单独验证 android aapt2 daemon (预期够, aapt2 daemon 通信量小)。建议 x86 CI 真实项目验证; 若 aapt2 daemon 需大 shm, runtime 加 --shm-size。
- **mac/win 原生构建**: tauri macOS .dmg / Windows .exe 需原生 OS (v6.0 决策), 容器化沙箱无法构建, 推后原生 runner / CI matrix。
- **v6.1 真实产物签名验证**: android apk 现可产 (本版本), apksigner 真实签名验证可做 (v6.1 留 mock); mac/win 待原生构建链路。

## 约束 (对后续版本)

- BINARY_APP 构建目标三形态: tauri_linux (默认, 桌面包) / web (dist) / capacitor_apk (apk)。新增 target 在 BuildTarget 枚举 + DEFAULT_BUILD_IMAGES + DeployConfig.for_type 三处注册。
- android-builder 镜像强制 amd64 (aapt2 x86_64 ELF); capacitor 7 需 JDK 21。
- build_target 通过 conversation_config["sandbox"]["target"] 配置; capacitor_apk 需 memory_limit_mb=4096。
- capacitor 项目需配 kotlin 版本统一 (BUILD_GUIDE 提示)。
- 镜像构建 smoke 标 slow (android 镜像 3.58GB, Rosetta 环境慢), CI 默认 skip。
