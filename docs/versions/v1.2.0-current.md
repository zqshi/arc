# v1.2.0 Current — AI对话引擎增强与产品可视化

> 状态: 进行中
> 起始 commit: 0846be3 (2026-05-22)
> 上一版本: [v1.1.0](v1.1.0-snapshot.md)

## 版本目标

v1.1.0 完成代码质量加固后, 本版本聚焦对话驱动引擎的核心能力: AgentLoop 可靠续写、DDD方法论注入、原型产品预览、交付物状态一致性。目标是让"一次对话产出完整产品设计"的体验真正可用。

## 版本验证标准

1. 对话模式产出的交付物, 侧边面板状态与聊天气泡标记严格一致
2. 原型交付物点击"产品预览"可在新标签页中交互式跳转浏览
3. 技术架构交付物产出后, 项目领域模型视图自动出现战略设计(子域/限界上下文/上下文映射)
4. AgentLoop 长输出不截断, 自动续写对用户透明
5. AutoPilot 模式可持续推进直到全部交付物完成或需要用户澄清

## 版本范围

**做什么:**
- AgentLoop 生产级引擎 (finish_reason续写/交付物验证重试/预算超时)
- 交付物拆分为8环节 (交互设计/视觉规范/原型设计独立)
- DDD+TDD 方法论条件注入 (dev_report schema重构)
- 项目级领域模型视图 (tech_architecture自动提取/战略战术可视化)
- AgentLoop 目标驱动改造 + AutoPilot 自驾模式
- 交付物状态不一致修复 (regex/JSON解析/race condition三层修复)
- 原型产品预览 (Blob URL隔离渲染/真实页面跳转)
- DDD战略设计注入 tech_architecture schema
- 前端 AbortError 处理

**不做什么:**
- S3+BaaS 原型托管 → v2.0.0
- 云端部署/定价模型 → v2.0.0
- project.py 拆分 → v2.0.0
- 集成市场(GitHub/GitLab/CI) → v2.0.0

## 对后续版本的约束

- AgentLoop 的 LoopConfig 已从项目 conversation_config 读取, 后续可扩展为用户级配置
- tech_architecture schema 新增 domain_design 字段, AI 产出的技术方案必须包含战略设计
- 原型预览当前使用 Blob URL, 迁移到 S3+BaaS 时需替换为持久化 URL
- DomainModelExtractor 按 name 去重合并, 多个 todo 产出的领域模型会累积到项目级
- AutoPilot 最大轮次 12 轮, 后续可根据任务复杂度动态调整
