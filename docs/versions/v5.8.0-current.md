## 关键决策

### 1. 拆分原则：行为不变 + 测试护航
- 纯重构，不改业务逻辑
- 拆分前确保现有测试覆盖，拆分后全量回归通过
- 不引入新依赖

### 2. tool_loop 拆分方案
- `tool_loop_metrics.py`: ToolLoopMetrics + ToolLoopEvent（数据类）
- `tool_loop_adapters.py`: _call_anthropic / _call_openai / _parse_* （LLM provider 适配）
- `tool_loop.py`: ToolAwareLoop 主类 + run + _execute_tool_with_retry

### 3. pipeline/service 拆分方案
- 主类保留 initialize/start/confirm/rollback/execute 等核心流程
- `_hooks.py`: _extract_experience / _notify_github / _feedback_experience_confidence / _collect_prior_artifacts / _merge_domain_model / _trigger_deployment（辅助 hook）

### 4. prompts 拆分方案
- `artifact_schemas.py`: ARTIFACT_SCHEMAS dict（纯数据，独立可维护）
- prompts.py 保留 system prompt + 构建函数，import artifact_schemas

### 5. 模板 embed 自动生成
- release hook 提取模板后，调 LLM embed(template.title + description + patterns) 生成 embedding
- 失败 graceful（embedding=None，匹配时该模板不参与向量搜索）
