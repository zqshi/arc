# v3.1.0 Snapshot — 领域模型影响分析

> 完成日期: 2026-06-01
> 起始 commit: a2a8ba7
> 上一版本: [v3.0.0](v3.0.0-snapshot.md)
> 升级路径阶段: Phase 2 / 3

## 版本目标

模型变更时自动分析对进行中需求的影响，给出风险等级和处理建议。

## 交付物

1. **风险矩阵**: 21 条规则 (7 PhaseType × 3 ModelChangeScope → 5 RiskLevel)
2. **聚合引用提取器**: 4 种模式识别 (data_model, event_storming, domain_design, implementation)
3. **ImpactAnalyzer**: 自动找出受影响 ACTIVE todos，按风险排序，生成 ImpactReport
4. **ImpactReport 值对象**: max_risk / has_critical / blocked_count 属性
5. **API**: POST /projects/{id}/domain-model/impact-analysis
6. **+34 tests** (928 total)

## 关键决策

| 决策 | 选项 | 理由 |
|------|------|------|
| Todo↔聚合关系 | 从交付物提取 vs 显式记录 | 提取式零维护成本，无需用户手动标注 |
| 风险矩阵 | 确定性规则 vs LLM 判断 | 规则可审计、零延迟、可测试 |
| ImpactReport | 可变 vs 不可变 | frozen dataclass：报告产出即不变，适合存档 |

## 对后续版本的约束

- Phase 3 可直接 `ImpactAnalyzer.analyze()` 获取报告
- 高风险 items 的 `recommendation` 字段已包含"暂停"建议文案
- `assess_risk()` 和 `risk_recommendation()` 可被 Phase 3 编排器复用
