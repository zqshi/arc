# v6.15.0 Snapshot — 过程约束依赖守卫治理

## 目标

审查三模式默认执行逻辑时发现: FREE 模式 soft 放行允许"没需求就开发/没原型就写代码", 且 STRICT 与 FREE 两套顺序逻辑分叉 (STRICT 走 phase 顺序检查, FREE 走 deliverable 依赖检查)。确立设计原则——依赖约束 (DAG) 是三档共享硬不变量, 不该由模式开关决定——并据此修正 DAG、废除 soft 放行、让 STRICT 链路也过 DAG 守卫, 清理 ProcessConfig 死字段, 补后端模式守卫。

## 交付

- **T1**: DAG 补全 (补 5 条依赖边: prototype→tech_architecture/app_code、app_code→dev_report/test_report、experience_card→dev_report; 加无环校验)
- **T2**: 废除 soft 放行 (删 GateProfile 的 dependency_block_mode/dependency_hard_block + ConversationGateResult.dependency_warning; 依赖约束三档统一硬阻断)
- **T3**: STRICT 链路补 DAG 守卫 (_evaluate_phase_gate 先过 DAG, 覆盖 skip 阶段缺口)

- **T5**: 后端模式守卫 (pipeline 5 写操作接入 _require_pipeline_mode, FREE/MODERATE→409 mode_mismatch; 真相源 todo.project→project.process_constraint) + create 持久化 bug 修复
- **T6**: 历史数据回填 migration (z18_backfill_process_constraint, 实测修正 959 个 pipeline→free 为 strict)

## 关键技术决策

1. **依赖约束 (DAG) 是三档共享硬不变量**: 不该由模式开关决定 (dependency_block_mode 是设计错误)。三模式差异只在"遍历策略 + 校验严格度"两维, 交付标准 (11 项 REQUIRED_DELIVERABLES) 全档一致。
2. **FREE 的"自由"语义**: 在可推进集合 (入度为0节点) 里自由选下一个, ≠ 无视依赖强行跳。丢掉的只是"在没原型时硬写代码"这种本就产出垃圾的行为。
3. **DAG 是交付物顺序唯一真相源**: STRICT 的 phase 顺序检查 (编排) 与 DAG 守卫 (依赖) 职责不同, 共存不合并。
4. **ProcessConfig 退化为 constraint 容器**: gate 行为由 GateProfile 接管; 不再加行为字段。
5. **模式守卫真相源 = project.process_constraint** (单一源); todo 无 project 回退 todo.execution_mode。不往 todo 加 constraint 字段 (避免第三处重复存同值)。
6. **create 持久化 bug 教训**: ProjectRepository 新增持久化字段必须同步 create + to_entity 两处, 否则 ORM default 静默覆盖, entity↔DB 不一致极难发现。

## 对后续版本的约束

- 依赖约束 (DAG) 是三档共享硬不变量, 禁止再引入 per-mode 的 dependency_block 开关。
- DAG 是交付物顺序的唯一真相源; STRICT 的 phase 顺序检查与 DAG 守卫职责不同 (前者编排, 后者依赖), 共存不合并。
- 新增交付物类型必须: (a) 加入 DELIVERABLE_DEPENDENCIES (b) 确保图无环 (test_graph_is_acyclic 守护) (c) 若是类型裁剪产物 (如 build) 走 _BUILD_ONLY 不入核心图。
- ProcessConfig 仅持 constraint, 不再加行为字段 (gate 行为由 GateProfile 接管); 新增过程行为参数应进 GateProfile 而非 ProcessConfig。
- pipeline 写操作受模式守卫保护 (_require_pipeline_mode), 新增 STRICT 专属写端点必须接入守卫。
- ProjectRepository 新增持久化字段必须同步在 create 与 to_entity 两处 (create bug 教训)。
- 延续 v6.9-v6.14 约束。
