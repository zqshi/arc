## 版本目标

消化 v2.1.0 后质量审计发现的技术债务（测试覆盖不足、大文件超限、部署配置占位符），同时推进交互体验改善（交付物抽屉挤压式布局）。以"还债+打磨"为主，不引入新功能。

## 关键决策

1. **api/client 架构**: 从 class-based ApiClient 改为函数式组合 (factory functions returning method records) — 支持 tree-shaking, 模块独立, 无 this 绑定问题
2. **seeds 拆分策略**: 按内容类型 (artifacts/messages) 而非按领域 (users/projects) 拆分 — 因为 seeds 数据结构以产出物和消息为维度组织
3. **k8s 参数化方式**: 选择 kustomize images transformer 而非 envsubst — 原生 kustomize 能力, 无额外工具依赖, 与 kustomize 生态一致
