## 关键决策

1. **scan_status 字段**: idle → scanning → completed/error，持久化到 Project 实体
2. **逻辑删除**: deleted_at 字段 + 列表默认过滤，保留硬删除供管理员使用
3. **循环依赖解法**: artifact/service.py 顶层 import 移除，使用延迟导入
4. **chat_with_tools()**: 统一接口，tool_loop 不再穿透 adapter 私有属性

## 对后续版本的约束

- Repository 接口补齐后，后续新增 repository 必须在 domain 层定义接口
- chat_with_tools() 建立后，后续 LLM 工具调用只走此接口
- 逻辑删除建立后，所有实体删除默认走逻辑删除路径
