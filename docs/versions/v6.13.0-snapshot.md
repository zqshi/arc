## 关键决策

### 方向 A 限定版 (签名链路真实化 + 凭证预留)
候选方向 (真实签名/测试债务/聚合边界/mac-win原生/runtime加固) 中选 A: 把 v6.12 闭环的 android 构建链路接上真实签名验证, 同时修 v6.1 P3 凭证配置遗留。mac/win 真实签名卡凭证/环境, 本版只做"凭证预留配置项"让接口正确, 不做真实验证。

### notarytool --apple-id 用 apple_id 非 team_id (P3 修正)
v6.1 P3 误用 team_id 充当 --apple-id。真实 notarytool --apple-id 需 Apple ID 邮箱。SigningCredentials 加 apple_id 字段, AppleSigner 用 apple_id 作 --apple-id, team_id 仍作 --team-id。用户配齐 apple_id + developer_id + team_id + app_password 即可真实签名。

### L3 证伪 "AndroidSigner 是 mock"
L1-L3 真实端到端验证 (capacitor 7 → assembleRelease 5m22s --shm-size 2g → release apk → apksigner sign SIGN_OK → verify v1/v2/v3 全 true) 证伪: AndroidSigner 真调 apksigner, 链路真实可用。apple.py/windows.py 注释原写 "mock subprocess", 实为真实命令构造 (与 AndroidSigner 同理), 注释去 mock 措辞。

### slow 测试默认 skip
pyproject addopts `-m "not slow"` 让 5min 级真实构建测试 (test_android_build_real) 默认 skip, 避免污染日常 pytest。手动 `pytest -m slow` 跑。
