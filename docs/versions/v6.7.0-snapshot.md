## 版本目标

v6.6 全项目深度审计收尾后, 无自然驱动版本。本版本先修审计发现的 2 项 P1 基线必修(k8s 部署文档断裂 + 前端死代码), 后收敛 4 项运行时入口补全: 对话执行双轨统一(ConversationService 复用 ExecutionEngine)、签名/分发凭证配置 API、skill 运行时配置热重载、charter 遵守度门禁。

## 关键决策

- **对话执行双轨统一**: ConversationService(pipeline 模式)自实现 _tool_aware_stream 缺沙箱隔离/多worker/artifact抽取, 委托 ExecutionEngine 全具备。service.py 498→135 行, 删~360 行死代码(PURPOSE_TO_PHASE/_build_system_prompt/_tool_aware_stream), phase_scope legacy 彻底统一到 ContextAssembler
- **凭证写入链路接通**: infrastructure/crypto.py:encrypt() + Project.set_*_creds() 零调用, 读取侧解密已通但写入从未实现。补 DeployService.configure_*_creds + route(3端点), deploy 签名不再恒 skip
- **skill 配置 env→运行时API级**: AgentRegistry.reload() 原地重建(不替换单例, 透明); 修 LLM 持久化 LLM_PROVIDER 与 config env_prefix=ARC_ 不一致致配置重启丢失(全字段加 ARC_ 前缀)
- **charter 门禁走 LLM 延伸**: evaluate_conversation_gate 加 charter 参数, _run_llm_review 注入 charter_section, charter 违规可阻断推进(非规则引擎)
- **pipeline 模式不评 charter**: pipeline/gate 传 charter_section="", 记技术债务(本波只延伸对话模式)
