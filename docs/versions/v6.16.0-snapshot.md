## 关键技术决策

1. **process_constraint 单一真相源**: todo 不持 constraint 字段 (避免第三处重复存), TodoResponse 透传 project.process_constraint (resolve_names batch 查, 零 N+1); 独立 todo (无 project) fallback STRICT (原 execution_mode=PIPELINE 语义)。
2. **gate 阈值同源而非巧合相等**: 原硬编码 score<7/缺口>=3 与 STRICT GateProfile 巧合相等, 非同源; 改读 get_profile(constraint) 后, 若守卫放行非 STRICT 进 evaluate_gate, 阈值自动正确 (defense in depth)。
3. **needs_reorder 非死逻辑**: 三档 DELIVERABLES 恒等不意味 reorder 空操作 — reorder 把 tracker.required 重排到 canonical 顺序 (含用户自定义 conversation_config.required_deliverables), 仍有效; 只删 dict + 三别名。
4. **测试 savepoint 隔离优于 truncate**: 共享 dev DB 不能 truncate all (删真实数据); savepoint (join_transaction_mode=create_savepoint) 让被测 commit 退化为 savepoint release, teardown rollback 全部撤销, 零数据破坏 + 机制性根治残留。
5. **from_execution_mode 随 drop column 失效**: v6.15 留作迁移映射点, 但 z19 drop execution_mode 列后无迁移对象 (z18 已回填 process_constraint), 成死代码, 6.1 删除。
