## 关键决策

1. **经验反馈闭环策略**: todo 完成 = 注入的经验有贡献 → `apply_feedback(helpful=True)`。比逐条追踪"AI是否引用了这条经验"更简单且更准确（完成即正反馈）。
2. **GLOBAL scope 门槛**: reuse_count >= 3 且 confidence >= 0.8。防止低质量经验污染全局池。
3. **Scan diff 存储**: 存入 `domain_model["_scan_history"]` 而非新增数据库字段，避免 migration。
4. **冲突检测使用 LLM 而非规则引擎**: 适应任意领域模型结构，不需要预定义冲突规则。
