## 版本目标

让 Agent 从"只有嘴"变成"有手有脚"：对话模式装备 shell/文件/grep 工具，自动 clone + scan 代码仓库，AI 能独立操作项目代码。

## 交付物

- **Tool Use 完整链路**: ToolRegistry(5工具) → ToolAwareLoop(Anthropic+OpenAI) → conversation_strategy 路由 → ws/chat 事件广播
- **GitHub clone + scan**: connect_github 后自动 clone 到 `~/.arc/repos/`，自动触发代码扫描
- **Route 层逻辑抽取**: send_quick_message 业务逻辑移入 application 层
- **Bug 修复**: 扫描 SSE 竞态(永远卡住)、scanner_analysis import 错误、ToolAwareLoop metrics 缺失

## 关键决策

| 决策 | 选择 | 原因 |
|------|------|------|
| Tool Use 实现方式 | 独立 ToolAwareLoop 而非改造 AgentLoop | 职责分离，AgentLoop 保持纯文本模式 |
| LLM tools 调用 | tool_loop 穿透 adapter 访问底层 SDK | adapter 接口不支持 tools，重构推迟到 v2.4.0 |
| clone 路径策略 | `~/.arc/repos/{owner}/{repo}` | 统一管理，不干扰用户项目 |
| 扫描 SSE 竞态 | subscribe() 检查 is_running + 300s 超时 | 防止永久阻塞 |
