### v6.12 遗留小项 (可不依赖方向先行, 工作量小)

| # | 待办 | 工作量 | 说明 |
|---|------|--------|------|
| L1 | runtime `--shm-size` 验证/加固 | 30min | DockerSandboxRuntime 的 `docker run` 默认 64m shm (`runtime.py:_build_argv` 未加 --shm-size)。v6.12 android smoke 本地手动 --shm-size=2g 通过。需在 x86 CI 真实项目验证 aapt2 daemon 是否需大 shm; 若需, runtime 加 `--shm-size` (按 build_target 条件: capacitor_apk 给 2g) |
| L2 | capacitor kotlin BUILD_GUIDE 提示 | 20min | capacitor 7 项目需配 kotlin 版本统一 (stdlib 1.8.22 vs jdk8 1.6.21 重复类, checkDuplicateClasses 失败)。在 PROTOTYPE_BUILD_GUIDES 或 BUILD_GUIDE 加 android 项目配置提示 |
| L3 | android release build 验证 | 待 L2 | `cap build android` (release) 同受 kotlin 重复类影响。L2 项目配置正确后, 真实验证 release apk + apksigner 签名 (接 v6.1 mock) |

> L1-L3 是 v6.12 android 链路的收尾, 风险低。若选方向 E (runtime 防御加固) 可一并做。
