## 关键决策

### 1. 预览 vs 部署 存储分离
- **预览**：单页 HTML mockup，2MB/文件限制，路径 `previews/projects/{pid}/{vid}/...`，跟随版本可覆盖
- **部署**：完整前端工程构建产物（dist/），50MB 单文件上限 + 分片，路径 `deployments/{project_id}/{deploy_id}/`，不可变

### 2. 部署状态机
`pending → building → uploading → deployed → failed`，外加 `rolled_back`（手动标记，不删文件）

### 3. CDN 与 URL 规范
`https://{cdn_domain}/deployments/{project_id}/{deploy_id}/index.html`，短期 S3 直出，中期接 CDN

### 4. Agent 执行集成点
Agent 执行 → 构建产物 → 调用 DeployService.deploy() → S3 上传 → URL 回写

### 5. 上下文组装 Provider Pattern（T10/T11）
- 统一 `ContextProvider` 协议，每种上下文来源（项目/经验/对话历史/ReviewFeedback）实现独立 Provider
- `ContextAssembler` 按 token 预算和优先级组装
- `PromptBuilder.build_system_prompt()` 委托给 ContextAssembler
- ReviewFeedback 回注：评审反馈作为独立 ContextSegment 注入下次对话

## 领域模型设计

### Deployment 实体（domain/deployment/entity.py）
```python
@dataclass
class Deployment:
    id: UUID
    project_id: UUID
    version_id: UUID
    todo_id: UUID | None
    status: DeploymentStatus  # pending/building/uploading/deployed/failed/rolled_back
    deploy_type: DeployType  # static_site (future: container, serverless)
    build_command: str
    artifact_path: str
    deploy_url: str | None
    storage_prefix: str | None
    files_uploaded: int = 0
    error_message: str | None = None
    created_at: datetime
    deployed_at: datetime | None
```

### 值对象
- `DeploymentStatus`: pending/building/uploading/deployed/failed/rolled_back
- `DeployType`: static_site (future: CONTAINER, SERVERLESS, BAAS_APP)
- `DeployConfig`: build_command/artifact_path/cdn_domain

### ContextProvider 协议（application/context/protocol.py）
- `ContextProvider` Protocol：统一上下文来源接口
- `ContextSegment`：数据模型（role/priority/content）
- `ContextAssembler`：按 token 预算 + 优先级组装

## 约束（延续到后续版本）

- **沙箱依赖**：构建（npm run build）需在沙箱内执行。当前 sandbox_default_mode="none" 时，构建由 Agent 在 local 环境完成
- **不做容器部署**：本版本只做静态站点。容器/Serverless/BaaS 留给 v5.6.0+
- **不做 CI/CD**：构建由 Agent 触发，不引入独立 CI runner。Arc 设计哲学——AI 执行，人审批
- **DEVELOPMENT 阶段产物断层未解决**：T1-T12 未触及该问题，留给 v5.5.0
