# v1.1.0 Current — 代码质量加固与工程规范补全

> 状态: 进行中
> 起始 commit: 0b6bea1 (2026-05-21)
> 上一版本: [v1.0.0](v1.0.0-snapshot.md)

## 版本目标

v1.0.0 完成了多用户与团队的全栈实现, 但审计发现测试覆盖严重不足、部分接口缺少分页、前端核心组件过度膨胀。本版本聚焦代码质量加固, 为后续 v2.0.0 商业化打好工程基础。

## 版本验证标准

1. 所有列表 API 支持分页, 无全量返回
2. TodoDetail 拆分后, 每个文件不超过 400 行
3. 后端 pytest 通过, 新增 auth/route 测试
4. 前端 tsc --noEmit 零报错
5. docker-compose 无硬编码密码

## 版本范围

**做什么:**
- 修复 todo.py get_dependencies 缺失路由装饰器
- 后端列表接口补全分页参数
- Docker 密码外部化
- 前端 TodoDetail.tsx 拆分为独立子组件
- 前端消灭静默 .catch(() => {}) 错误处理
- 前端消除硬编码 localhost
- 补充 auth service 单元测试
- 补充 route 级冒烟测试

**不做什么:**
- routes 层到 application service 的全面重构 → v2.0.0
- infrastructure repo 全量实现 domain 接口 → v2.0.0
- 拆分 project.py 1023 行 → v2.0.0
- 引入 coverage 门槛 → 需先补足测试量

- TodoDetail 拆分后的子组件目录 `pages/todo/`, 后续新增 todo 相关组件放在此目录
- Docker 部署需通过 .env 注入敏感配置, 不允许在 compose 文件中硬编码
