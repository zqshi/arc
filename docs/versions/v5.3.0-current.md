## 关键决策

### 三层原型预览

| 层级 | 生成时机 | 存储 |
|------|---------|------|
| 需求 (Todo) | AI 产出 prototype artifact 时 | DB artifact.content + 可选 S3 publish |
| 版本 (Version) | 每次版本下有新 prototype 产出时自动聚合覆盖 latest | S3: `previews/projects/{pid}/{vid}/latest/` |
| 项目 (Project) | 不独立生成，等于当前 active 版本的 latest | — |

### 发布 vs 部署

- **发布 (release)** = 版本级别，所有需求完成 → Version.release() → snapshot 生成
- **部署 (deploy)** = 需求级别 pipeline phase，代码推送到运行环境
- 原型快照跟随版本 release，不是 deployment

### S3 路径规范

```
previews/projects/{project_id}/{version_id}/latest/index.html
previews/projects/{project_id}/{version_id}/snapshots/{yyyyMMddHHmmss}/index.html
```
