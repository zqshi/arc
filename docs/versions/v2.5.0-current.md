## 关键决策

1. **StreamManager 架构**: 进程级单例，后台 asyncio.Task 运行流式生成，events buffer + subscriber queue 支持 replay。WS 断开不影响后台生成和持久化。
2. **消息 ID 统一**: streaming message_id 作为 entity UUID，前后端同一 ID，dedup 自然生效。
3. **工具调用分组**: 新增 SerialBatch（同类型串行分组）+ 自动折叠已完成调用 + React state 控制展开。

## 对后续版本的约束

- ContextController 建立后，所有 LLM 调用必须走 ContextController.assemble()
- CompressionManager 接口稳定后，后续版本只增加压缩策略不改接口
- Prompt Cache 排序约束：静态内容必须放在 system prompt 前段
- StreamManager 单例需考虑多进程部署时的状态共享（当前适用于单进程 uvicorn）
