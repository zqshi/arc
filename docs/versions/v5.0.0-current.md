> **主题**: AI 回复中的 HTML 代码块自动 apply 到原型 iframe + 创建项目后自动扫描
> **前置**: v4.9.0 完成

---

## 版本目标

1. 对话中 AI 返回修改后 HTML → 前端自动检测 → apply 到 iframe（用户看到实时更新）
2. 创建项目关联本地目录后自动触发代码扫描
3. 项目原型预览增加「热更新」能力（对话产出 prototype 时自动刷新预览）

## 设计要点

### T1: HTML 代码块检测 + apply

在 `ChatMessages` 或 `UnifiedWorkspaceView` 中：
- 监听 AI 消息内容
- 正则检测 ````html\n...\n```` 代码块
- 如果当前有原型 artifact 在侧边栏打开 → 提供「应用修改」按钮
- 点击后通过 InteractivePrototype ref 调用 applyHtml

### T2: 创建后自动扫描

在 `create_project` 路由中，如果 `workspace_type == "local"` 且 local_path 有效：
- 创建完成后异步启动 scan

### T3: 原型热更新

当 `artifacts_extracted` WebSocket 事件到达且包含 prototype 类型时：
- 自动 re-fetch deliverables
- 如果侧边栏打开着原型 → 刷新其 content
