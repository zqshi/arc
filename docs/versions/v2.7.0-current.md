## 版本目标

1. **PR 自动创建** — git push 后自动创建 GitHub PR（可选），含 AI 生成的 PR description
2. **ConversationModeView 拆分** — 856 行超限，拆为独立子组件
3. **冲突检测与提示** — push 失败时给出冲突提示和建议操作

## 版本范围

**做什么:**
- git push 后可选自动创建 PR（使用 GitHub API）
- PR description 由 AI 根据 diff + todo 上下文生成
- ConversationModeView → ChatPanel + DeliverablePanel + ToolCallPanel 拆分
- push 失败时前端提示冲突原因和手动解决指引

**不做什么:**
- 冲突自动解决（rebase/merge）→ backlog
- 在线原型编辑 → backlog
- Memory 打分算法 → backlog
