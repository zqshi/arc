## 版本目标

Arc 核心交互哲学是**意图驱动 + Agent 自主推理**，但审计发现实现存在"买椟还珠"——意图驱动能力建好却没接线、或曾实现后被删除回归。本版本落地 prompt-upgrade-plan 路线图**第一批 6 处**（自由模式门禁 + 部署断点统一 + 澄清策略路由），解除 v6.3.0 前置阻塞。

## 关键决策

- **门禁分级走注册表**: GateProfile(free≥5/moderate≥6/strict≥7) 注册表分级，对话模式按 ProcessConstraint 选 profile，达阈值阻断而非仅记录。禁止 service 写 if 分支（与 v5.9.0 部署器注册点同构）
- **部署硬门禁**: `check_build_ready` 校验 build_status + dist 目录，`.ensure_ok()` 失败即抛，替代原先"不检查 build_status/只找 dist/静默 return"三重 graceful-skip，杜绝虚假部署
- **澄清策略路由**: clarification_strategy 枚举(FIRST_PRINCIPLES/VALUE_ASSESSMENT/SOCRATIC/SUFFICIENCY_FIRST) + route_strategy + STRATEGY_PROMPTS 注册表，按需求类型动态选方法论，替代固定6层苏格拉底
- **autopilot 门禁重试**: max_gate_retries=2，门禁卡点时反馈重试，超阈值截断避免死循环
- **复用 > 新建**: 升级是把规则执行版判断逻辑替换为 LLM prompt + 输出契约，复用现有数据流，非另起一套
